# 🧮 Calculator App

A simple calculator web application built using HTML, CSS, and JavaScript.

---

## 📌 Features

- Basic arithmetic operations (+, -, ×, ÷)
- Clear (AC) button
- Responsive design (mobile + desktop)
- Instant calculation result

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## 🚀 How to Use

1. Open the project in browser
2. Click number buttons
3. Select operator (+, -, ×, ÷)
4. Press "=" to get result
5. Use "AC" to clear screen
